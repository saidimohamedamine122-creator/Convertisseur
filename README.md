# 🔁 Convertisseur Multi-Unités (Python)

## 📌 Description
Programme en Python permettant de convertir :
- des longueurs
- des durées (temps)
- des températures

Le projet fonctionne via un menu interactif en console.

## 📂 Structure du projet
- Main.py → point d’entrée
- Menu.py → menu principal
- ConvertionLongueur.py → conversions de longueur
- ConvertionTemps.py → conversions de temps
- ConvertionTemperature.py → conversions de température

## ▶️ Utilisation
1. Lancer `Main.py`
2. Choisir une option dans le menu
3. Entrer les valeurs demandées
4. Appuyer sur Entrée pour revenir au menu

## 🛠️ Technologies
- Python 3
- Application console (CLI)
